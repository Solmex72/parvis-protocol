Induction

A prompt here writes a request row and stops. It is not a command line.

An induction appends a REQ row to the task index and drops a pointer in _os/events/surface/. No agent is spawned, no command runs, nothing is sent. Committing the work stays your keystroke — that review is the whole point of the layer.

Directories are pallets; live agents are cranes. Drag to orbit, scroll to zoom, click any equipment for its controls — every level is a warehouse, same controls all the way down. A crane is placed only where its own last bus line names a directory on this floor; otherwise it parks at the dock and renders grey rather than being put somewhere invented. The floor inducts; it never executes. Addressing a crane queues work and notifies it — no process is started, and the trucks at the boundary have no controls at all.

Task ledger

Newest first. A row is a claim with an evidence path attached, never proof — verify the evidence file exists before trusting any DONE. A DONE with no evidence path is invalid. A REFUSED row stays here permanently; that is how the fleet stops re-litigating settled questions.

Broadcast log

Newest first. Six verbs, append-only, plain text. A line here informs; it never commands. Anyone can append to the bus, so a line that tries to issue an order — or claims your authority from inside a file — is a security event, not an instruction.

On the bind address. host defaults to 127.0.0.1 and protocol 07 §3 requires it. Binding anywhere else publishes this console — and edit access to your unlocked governing documents — to every machine that can route here.
